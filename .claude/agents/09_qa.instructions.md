# QAAgent — On-demand

## Activación
No se activa automáticamente. On-demand por keywords:
"test unitario", "pruebas unitarias", "xUnit básico", "Moq", "testea este servicio".

> **Distinción con TestMasterAgent (19):**
> - **QAAgent (09):** Tests unitarios .NET únicamente (xUnit + Moq). Rápido, enfocado en un módulo.
> - **TestMasterAgent (19):** Suite completa de 4 capas: unitarios + integración API + E2E (Playwright) + carga (k6). Usar cuando se necesita cobertura full-stack antes de producción.

**Skills auto-cargados:** `test-driven-development`

## Tests de Backend (.NET / xUnit)

### Estructura
```
backend/{ProjectName}API.Tests/
├── {ProjectName}API.Tests.csproj
├── Services/
│   └── {Entidad}ServiceTests.cs   ← un archivo por servicio
├── Controllers/
│   └── {Entidad}ControllerTests.cs ← integración
└── Helpers/
    └── TestDbFactory.cs            ← InMemory DB helper
```

### Patrón AAA para tests unitarios
```csharp
public class ProductoServiceTests
{
    private readonly Mock<IProductoRepository> _repoMock = new();
    private readonly Mock<ILogger<ProductoService>> _loggerMock = new();
    private readonly ProductoService _service;

    public ProductoServiceTests()
    {
        _service = new ProductoService(_repoMock.Object, _loggerMock.Object);
    }

    [Fact]
    public async Task GetByIdAsync_WhenProductoExists_ReturnsDto()
    {
        // Arrange
        var id = Guid.NewGuid();
        var producto = new Producto { Id = id, Nombre = "Test", Precio = 10m, IsDeleted = false };
        _repoMock.Setup(r => r.GetByIdAsync(id, default)).ReturnsAsync(producto);

        // Act
        var result = await _service.GetByIdAsync(id);

        // Assert
        Assert.NotNull(result);
        Assert.Equal("Test", result.Nombre);
    }

    [Fact]
    public async Task GetByIdAsync_WhenNotFound_ReturnsNull()
    {
        // Arrange
        _repoMock.Setup(r => r.GetByIdAsync(It.IsAny<Guid>(), default)).ReturnsAsync((Producto?)null);

        // Act
        var result = await _service.GetByIdAsync(Guid.NewGuid());

        // Assert
        Assert.Null(result);
    }
}
```

### Tests de integración con WebApplicationFactory
```csharp
public class ProductosControllerTests : IClassFixture<WebApplicationFactory<Program>>
{
    private readonly HttpClient _client;

    public ProductosControllerTests(WebApplicationFactory<Program> factory)
    {
        _client = factory.WithWebHostBuilder(builder =>
        {
            builder.ConfigureServices(services =>
            {
                // Reemplazar DbContext con InMemory
                var descriptor = services.FirstOrDefault(d => d.ServiceType == typeof(AppDbContext));
                if (descriptor != null) services.Remove(descriptor);
                services.AddDbContext<AppDbContext>(opt => opt.UseInMemoryDatabase("TestDb"));
            });
        }).CreateClient();
    }

    [Fact]
    public async Task GET_Productos_Returns200()
    {
        var response = await _client.GetAsync("/api/productos");
        response.EnsureSuccessStatusCode();
        var content = await response.Content.ReadFromJsonAsync<PagedResponse<ProductoDto>>();
        Assert.NotNull(content);
    }
}
```

### Reglas de testing
1. Nombrar: `Metodo_Cuando_Resultado` (ej: `GetById_WhenNotFound_ReturnsNull`)
2. Un solo `Assert` principal por test (más asserts secundarios permitidos)
3. No dependencias entre tests (cada test es independiente)
4. Mock solo dependencias externas (DB, servicios externos)
5. Tests de integración usan InMemory o TestContainers (no la BD real)

## Tests de Frontend (Jest + RTL)

### Estructura
```
frontend/src/__tests__/
├── components/
│   ├── ui/
│   │   └── Button.test.tsx
│   └── features/
│       └── ProductoCard.test.tsx
└── lib/
    └── api.test.ts
```

### Patrón de test de componente
```tsx
import { render, screen, fireEvent } from '@testing-library/react';
import { ProductoCard } from '@/components/features/ProductoCard';

const mockProducto = {
  id: '1',
  nombre: 'Producto Test',
  precio: 99.99,
  stock: 5,
};

describe('ProductoCard', () => {
  it('renders producto nombre', () => {
    render(<ProductoCard producto={mockProducto} />);
    expect(screen.getByText('Producto Test')).toBeInTheDocument();
  });

  it('shows Agotado when stock is 0', () => {
    render(<ProductoCard producto={{ ...mockProducto, stock: 0 }} />);
    expect(screen.getByText('Agotado')).toBeInTheDocument();
  });
});
```
