# TransKeyTours — Bocas del Toro 2026

Landing page profesional para el paquete turístico de **San Carlos, Costa Rica → Bocas del Toro, Panamá**.

## Estructura

- `index-final.html` — Página principal (single-file, todo embebido)
- `social.html` — Hub social con links a redes
- `images/` — Galería de destinos y fotos del tour
- `tools/` — Scripts utilitarios de mantenimiento

## Cómo usar

1. **Abrir localmente:**
   - Abre `index-final.html` directamente en el navegador, o
   - Usa un servidor local: `python -m http.server 8080`

2. **Publicar:**
   - El repositorio está configurado para **GitHub Pages** en `main`
   - URL: `https://jrodri22.github.io/Transkeytour/index-final.html`

- Hero con video de fondo + poster fallback
